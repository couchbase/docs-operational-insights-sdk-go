= Go Insights SDK {sdk_dot_minor}

The Insights Go SDK allows you to connect to an xref:entreprise-analytics:intro:intro.adoc[Operational Insights] cluster from Go.
For connecting to a Couchbase Server Cluster -- self-managed, or Capella Operational --
see our xref:go-sdk:hello-world:overview.adoc[Go Operational SDK].

TIP: Connecting to an xref:columnar:intro:intro.adoc[Operational Insights _Capella_] cluster from Go currently requires a xref:go-columnar-sdk:hello-world:overview.adoc[Go Columnar SDK].
